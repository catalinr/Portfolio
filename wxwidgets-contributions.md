## [<img src="https://wxwidgets.org/downloads/logos/blocks.svg" width="40" />](https://wxwidgets.org) wxWidgets contributions

🏦 **Purpose:**  Cross-platform C++ library that lets developers create applications for Windows, macOS, Linux and other platforms with a single code base, using a truly native look and feel because it uses the platform's native API rather than emulating the GUI.

⚙️ **Tech stack:** `C++`

🔓 **Source code:** Open source, [wxWidgets](https://github.com/wxWidgets/).

🧑‍💻 **Role:** Active developer and contributor · forum moderator.

🚀 **Outcome:** Bug fixes, new features, code reviews, up-to-date Romanian translation; re-test / re-evaluate, resolved and closed lots of bugs and issues. Several hundred commits in total; mentored successful GSoC projects in [2017](gsoc-2017.md) and [2014](gsoc-2014.md); forum discussions and moderation for about 20 years.
