## [<img src="https://mega.io/wp-content/themes/megapages/megalib/icons/logos/mega.svg" width="24" />](https://mega.io) Mega, MEGAchat [<img src="https://cdn.simpleicons.org/github/000000/ffffff" width="24" />](https://github.com/meganz/MEGAchat)

🏦 **Purpose:** cross-platform SDK extension that adds support for chat, meetings, schedules to Mega products built on top of it.

🚀 **Functionality:** provides complete end-to-end encryption for chat (text, voice, video), meetings, schedules, in either public or private setup via `MegaChatApi` interface. Built for Windows, Linux, MacOS, iOS and Android, for all architectures that each supported, out of x86-64, x86, arm64, arm. [<img src="https://cdn.simpleicons.org/github/000000/ffffff" width="20" />](https://github.com/meganz/MEGAchat/commits/master/?author=cra%40mega.nz)
